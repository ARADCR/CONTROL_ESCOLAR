# CONTROL ESCOLAR

## Descripción
Aplicación para gestionar los procesos escolares de una Institución Educativa, controlando alumnos, profesores, procesos administrativos y directivos.

## Objetivo
Desarrollar un sistema de control escolar integral que permita realizar operaciones CRUD y generar reportes mediante interfaces modulares.

## Pila Tecnológica
* Backend: Laravel (según configuración de .gitignore)
* Frontend: JavaScript / HTML / CSS
* Control de Versiones: Git / GitHub
